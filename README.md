# Course Platform
A lightweight e-learning platform prototype that allows users to browse courses, watch lessons, and interact with the course player.

# Tech Stack
* Next.js
* TypeScript
* Tailwind CSS 
* Zustand
* react-youtube


# Getting Started
Follow these steps to run the project locally:

1. Install dependencies:
```bash
npm install
```

2. Run the development server:
```bash
npm run dev
```
